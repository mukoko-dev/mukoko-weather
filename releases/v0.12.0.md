title: Weather for anywhere you search or stand
---

This release makes search, the home page and nearby airports work properly anywhere in the world, so places like Phuket and Bangkok behave the same as places at home.

## Improved

- **Search works worldwide.** Searching for a country now lists its cities, so "Thailand" shows Bangkok, Phuket and more. Search no longer offers the middle of a country, a province or an ocean as if it were a place, so you only see towns, cities and other real places.
- **Your location works anywhere.** "Use my location" now gives you a real, named place wherever you are, instead of falling back to a city far away. If a well-known city is close by, you land on that city's page, so one city has one address.
- **Shorter addresses for well-known places.** Typing a city's plain name in the address, such as phuket, takes you straight to its full page, phuket-th.
- **Better heights above sea level.** For places we have not stored, the elevation shown on the page now comes from the weather forecast's own terrain data, instead of a placeholder of zero.
- **Nearby airports anywhere.** The nearby-airport weather card now finds airports with live reports wherever you are, not only a short built-in list. Near Phuket it now shows Phuket International.
- **More countries behind the scenes.** Country information for the whole world has been added to our places data.

## Fixed

- **No more dead-end results for countries.** Searching for a country used to offer a page for its centre point, which was not a useful place to get weather for. Those results are gone.
- **"No airport nearby" where there is one.** The airport card no longer says there is no airport within range when one is only a short distance away.

## Known issues

- **Place names for a new spot can be general.** When we name a place on the spot, we use a city-level name, so you may see a municipality name rather than the town you know.
- **Developer API keys are not live yet.** Behind-the-scenes sign-in groundwork for upcoming developer API keys is in place, but nothing is available to use yet.
